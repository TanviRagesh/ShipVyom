## Project Overview

This frontend web application, named **ShipVyom**, is built using React.  
It displays the status of logistics shipments in a simple and responsive dashboard.

The application uses mock data to show shipment details and focuses on clean UI, proper component structure, and user-friendly design.

---

## Tech Stack

- React
- Vite
- Tailwind CSS
- JavaScript

---

## How to Download and Run the Project

### Prerequisites

Make sure you have the following installed:

- Node.js (version 16 or above)
- npm
- Git

### Steps to Run Locally

```bash
git clone https://github.com/TanviRagesh/ShipVyom.git
cd ShipVyom
npm install
npm run dev

Open your browser and go to: http://localhost:5173
``` 
## Features

- Displays shipment status and details
- Filter shipments based on status
- Sort shipments by date, status, or tracking number
- Shows loading and error states
- Fully responsive design

---

## Design Choices

- The application is divided into reusable components for better code structure.
- Mock API data is used to simulate real-world behavior.
- Tailwind CSS is used for consistent styling and responsiveness.
- React hooks are used to manage data and UI states.

---

## Challenges Faced

- Managing loading, error, filtering, and sorting states together
- Making the UI responsive on all screen sizes
- Keeping the code clean and readable
